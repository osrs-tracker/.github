# Security policy

This policy covers every public repository in the osrs-tracker organization that doesn't have its own `SECURITY.md`.

## Supported versions

Only what is deployed from each repository's `main` branch is supported. Older tags and releases get no fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead:

- **GitHub:** the "Report a vulnerability" button on the repository's **Security** tab (private vulnerability
  reporting).
- **Email:** the contact in [security.txt](https://osrs-tracker.freekmencke.com/.well-known/security.txt).

Include the affected repository or URL, steps to reproduce, and the impact you expect.

## What to expect

- An acknowledgement within a week.
- A fix, or an explanation of why no change is needed, as soon as is practical for a project maintained by one person.
- Credit in the advisory if you want it.

There is no bug bounty.
